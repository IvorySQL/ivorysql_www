# IvorySQL Website

Official website for [IvorySQL](https://www.ivorysql.org), an open source Oracle-compatible PostgreSQL database.

Built with Next.js 15, React 19, and Tailwind CSS 4.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Stack

- **Next.js 15** with App Router
- **React 19**
- **Tailwind CSS 4**
- **shadcn/ui** components
- **TypeScript**
- **MDX** for blog/news/events content (`content/blog`, `content/news`, `content/events`)

## Deployment

The website is automatically deployed to [Vercel](https://vercel.com/) each time the `main` branch receives a new push.
