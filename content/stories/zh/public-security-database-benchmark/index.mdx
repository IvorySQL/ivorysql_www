<h2 id="background">项目背景</h2>
<p>该客户是公安技侦条线的国产数据库替代项目，核心诉求是验证 IvorySQL 能否在海量案件数据场景下——包括协同办案、专题数据录入、第三方资源录入等——稳定承载高并发写入与实时查询，从而替换原有的 Oracle 数据库。</p>

<h2 id="test-environment">现场测试环境</h2>
<p>测试采用 3 台数据库服务器组网，通过千兆与万兆双网络接入，模拟真实业务场景下的数据吞吐与查询压力：</p>
<ul>
  <li><strong>数据库服务器</strong>：CPU 海光 C86 7285，256GB 内存，2.4TB SAS 硬盘，操作系统 Kylin V10 SP1</li>
  <li><strong>测试数据</strong>：TB_EVT 表，单个文件 4GB，共导入 365 个文件，对应库表 365 个分区</li>
</ul>

<p>围绕公安技侦真实业务场景，设计了以下测试用例：</p>
<ul>
  <li>批量入库场景测试</li>
  <li>DISTINCT 计算测试</li>
  <li>并发随机读场景测试</li>
  <li>并发随机读 + 排序场景测试</li>
  <li>逐条入库场景测试</li>
  <li>并发随机读测试 + 逐条入库场景</li>
  <li>超高负载的稳定性测试</li>
</ul>

<h2 id="customization">定制与兼容能力</h2>
<p>为满足公安技侦业务的特殊需求，项目团队在 IvorySQL 之上完成了大量定制开发与性能调优：</p>
<ul>
  <li>定制全文检索功能</li>
  <li>实现虚拟分区的功能</li>
  <li>兼容 Oracle 的 system 分区</li>
  <li>兼容项目中用到的 Oracle 字典表</li>
  <li>实现分区表索引并行创建的功能</li>
  <li>实现表结构和索引的自动复制功能</li>
  <li>实现完备的多模态数据库插件生态与扩展能力</li>
  <li>优化外部表功能，使外部表更加符合项目的实际需求</li>
  <li>持续测试及调整数据库参数，尽量能发挥服务器的性能</li>
  <li>实现数据文件的高速入库，相比常规入库方式速度有数倍提升</li>
  <li>兼容 Oracle 的交换入库功能，并且在 Oracle 基础上增加了定制功能</li>
  <li>实现数据文件备份及恢复的功能，相比常规的备份方式速度有数倍提升</li>
  <li>实现数据文件自动挂载，实现不同库之间数据同步，相比常规的数据同步方式速度有数倍提升</li>
</ul>

<h2 id="outcome">项目成果</h2>
<p>IvorySQL 已在公安技侦业务中深度融合，为构建"感知－分析－决策－行动"的智慧公安提供坚实的国产底座支撑。项目先后参与了公安部、信通院、广东省、河北省、山西省等十余个省份的公安技侦业务国产数据库替代工作。</p>
