<h2 id="background">Background</h2>
<p>This customer's project was a domestic database replacement initiative for a criminal investigation (technical reconnaissance) unit within China's public security system. The core requirement was to verify whether IvorySQL could reliably handle high-concurrency writes and real-time queries against massive case data — covering joint case-handling, specialized data entry, and third-party data intake — in order to replace the existing Oracle database.</p>

<h2 id="test-environment">On-Site Test Environment</h2>
<p>The benchmark used three database servers networked over dual Gigabit and 10-Gigabit switches to simulate the throughput and query load of real production scenarios:</p>
<ul>
  <li><strong>Database servers</strong>: Hygon C86 7285 CPU, 256GB RAM, 2.4TB SAS storage, Kylin V10 SP1 OS</li>
  <li><strong>Test data</strong>: table <code>TB_EVT</code>, loaded from 365 individual 4GB files, mapped to 365 table partitions</li>
</ul>

<h2 id="test-scenarios">Test Scenarios</h2>
<p>Test cases were designed around real criminal-investigation workloads:</p>
<ul>
  <li>Batch loading scenario test</li>
  <li>DISTINCT computation test</li>
  <li>Concurrent random read scenario test</li>
  <li>Concurrent random read + sort scenario test</li>
  <li>Record-by-record loading scenario test</li>
  <li>Concurrent random read + record-by-record loading test</li>
  <li>Extreme-load stability test</li>
</ul>

<h2 id="customization">Customization &amp; Compatibility Work</h2>
<p>To meet the specific requirements of criminal-investigation workloads, the project team built substantial customizations and performance tuning on top of IvorySQL:</p>
<ul>
  <li>Custom full-text search functionality</li>
  <li>Virtual partitioning support</li>
  <li>Compatibility with Oracle <code>SYSTEM</code> partitions</li>
  <li>Compatibility with the Oracle dictionary tables used in the project</li>
  <li>Parallel index creation for partitioned tables</li>
  <li>Automatic replication of table structures and indexes</li>
  <li>A complete multi-model database plugin ecosystem and extensibility</li>
  <li>Optimized foreign-table functionality to better fit the project's real-world needs</li>
  <li>Continuous testing and parameter tuning to maximize server performance</li>
  <li>High-speed data file loading, several times faster than conventional ingestion</li>
  <li>Compatibility with Oracle's exchange-loading feature, extended with custom capabilities beyond Oracle's own implementation</li>
  <li>Data file backup and recovery, several times faster than conventional backup methods</li>
  <li>Automatic data file mounting for cross-database data synchronization, several times faster than conventional sync methods</li>
</ul>

<h2 id="outcome">Outcome</h2>
<p>IvorySQL is now deeply integrated into public security criminal-investigation operations, providing a solid domestic database foundation for a "sense–analyze–decide–act" smart-policing architecture. The project has since supported domestic database replacement work for the Ministry of Public Security, the China Academy of Information and Communications Technology, and criminal-investigation departments across more than ten provinces, including Guangdong, Hebei, and Shanxi.</p>
