      <p>
        IvorySQL 4.4 was officially released on March 10, 2025. This new version offers full support for PostgreSQL 17.4, introduces a host of new features, and addresses known issues.
      </p>

      <h2 id="enhancements">Enhanced Features</h2>
      
      <h3 id="pg-17-3">PostgreSQL 17.3 Enhancements</h3>
      <ul>
        <li>Strengthened protection of PQescapeString and related functions against invalid encoding input strings.</li>
        <li>Restored automatic truncation of database and usernames occurring in connection requests.</li>
        <li>Excluded parallel workers from connection privilege checks and limits.</li>
        <li>Removed the "Lock" suffix from LWLock wait event names.</li>
        <li>Fixed an issue where stale results might be reused in window aggregations.</li>
        <li>Prevented checkpoints from starting during relation truncation.</li>
      </ul>
      <p>For more details, please visit the <a href="https://www.postgresql.org/docs/release/17.3/" target="_blank">PostgreSQL 17.3 Release Notes</a>.</p>

      <h3 id="pg-17-4">PostgreSQL 17.4 Enhancements</h3>
      <ul>
        <li>Improved libpq's quoting function behavior.</li>
        <li>Fixed a minor memory leak in pg_createsubscriber.</li>
        <li>Fixed the meson build system to correctly detect the availability of bsd_auth.h system headers.</li>
      </ul>
      <p>For more details, please visit the <a href="https://www.postgresql.org/docs/release/17.4/" target="_blank">PostgreSQL 17.4 Release Notes</a>.</p>

      <h2 id="new-features">New Features</h2>
      
      <h3 id="arm64">1. ARM64 Architecture Full-Platform Media Packages</h3>
      <p>Provides full-platform media packages suitable for the ARM architecture, supporting mainstream operating systems at home and abroad, including Red Hat, Debian, Kylin, UOS, NSAR OS, etc.</p>

      <h3 id="x86">2. X86 Architecture Full-Platform Media Packages</h3>
      <p>Provides full-platform media packages suitable for the X86 architecture, supporting mainstream operating systems at home and abroad, including Red Hat, Debian, Kylin, UOS, NSAR OS, etc.</p>

      <h3 id="kernel-design">3. New Kernel Architecture Design Column</h3>
      <p>Added a series of kernel architecture design documents, with the first theme being Oracle compatibility, deeply exploring the framework, design, and implementation principles of each module to help users understand the Oracle compatibility framework. Currently, architectural design documents for two modules have been released:</p>
      <ul>
        <li>Analysis of the Dual Parser Architecture Principle in the Oracle Compatibility Framework</li>
        <li>Analysis of the initdb Architecture Principle in the Oracle Compatibility Framework</li>
      </ul>

      <h3 id="chatroom">4. IvorySQL Official Website Chatroom Feature</h3>
      <p>Added a chatroom feature to the official website, supporting intelligent interactions and Q&A sessions related to IvorySQL.</p>

      <h2 id="resolved-issues">Resolved Issues</h2>
      <ul>
        <li>Incomplete SQL when using invisible columns and pg_dump.</li>
        <li>EulerOS installation package issues.</li>
      </ul>
      <p>For more details, see the <a href="https://github.com/IvorySQL/IvorySQL/releases/tag/IvorySQL_4.4" target="_blank">IvorySQL 4.4 Release Notes</a>.</p>
