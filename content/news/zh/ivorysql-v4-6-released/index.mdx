<p>2025 年 9 月 10 日，IvorySQL 4.6 正式发布！</p>
<p>新版本全面支持 PostgreSQL 17.6，新增多项新功能，并修复了已知问题。</p>

<h2 id="enhancements">增强功能</h2>
<p>PostgreSQL 17.6 增强功能：</p>
<ul>
  <li>加强规划器估计函数中的安全检查。</li>
  <li>防止 pg_dump 脚本被用于攻击运行还原操作的用户。</li>
  <li>在 pg_dump 输出的注释中包含的名称中将换行符转换为空格。</li>
  <li>修复 BRIN numeric_minmax_multi_ops 支持函数中的距离计算错误。</li>
  <li>避免我们将接受的 XML 输入大小出现倒退问题。</li>
</ul>
<p>更多细节请参阅 <a href="https://www.postgresql.org/docs/release/17.6/" target="_blank" rel="noopener noreferrer">PostgreSQL 发布说明</a>。</p>

<h2 id="new-features">新增特性</h2>
<ul>
  <li>升级至 PG 17.6 内核。</li>
  <li><strong>兼容 MongoDB 的解决方案：</strong>使用 FerretDB 和 DocumentDB 提供兼容 MongoDB 的解决方案。</li>
  <li><strong>全平台 LoongArch 打包：</strong>提供适用于 LoongArch 架构的全平台介质包，支持国内外主流操作系统，包括红帽、Debian、麒麟、统信和凝思等操作系统。还支持 x86、ARM 和 MIPS 架构。</li>
  <li><strong>IvorySQL 在线试用：</strong>为用户提供基于 Web 的平台，可在线体验 IvorySQL V4.6，直接通过浏览器界面进行数据库交互。</li>
  <li><strong>容器化部署支持（Docker Swarm）：</strong>支持在 Docker Swarm 环境中部署单机 IvorySQL 数据库和高可用集群。</li>
  <li><strong>容器化部署支持（Kubernetes）：</strong>支持使用 Helm 在 Kubernetes（K8S）上部署单机 IvorySQL 数据库和高可用集群。</li>
  <li><strong>IvorySQL Cloud v4.0 已发布：</strong>IvorySQL Cloud 平台目前支持 IvorySQL v4 数据库的订阅管理，以及其周边生态系统的全面管理。</li>
</ul>

<h2 id="fixed-issues">修复已知问题</h2>
<ul>
  <li>修复 aarch64 平台上缺少 libcrypt 的问题。</li>
  <li>修复执行 make 和 make install 时，前缀为 test_ 的扩展被错误地编译和安装问题。</li>
  <li><strong>文档：</strong>修复一些拼写错误。</li>
  <li><strong>文档：</strong>修复安装部分的文档错误。</li>
  <li><strong>文档：</strong>更新社区贡献流程。</li>
</ul>
