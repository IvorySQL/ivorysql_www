<p>
  IvorySQL 4.4 已于 2025 年 3 月 10 日正式发布。新版本全面支持 PostgreSQL 17.4，新增多项新功能，并修复了已知问题。
</p>

<h2 id="enhancements">增强功能</h2>

<h3 id="pg-17-3">PostgreSQL 17.3 增强功能</h3>
<ul>
  <li>加强 PQescapeString 及相关函数对无效编码输入字符串的防护。</li>
  <li>恢复在连接请求中出现的数据库和用户名的自动截断。</li>
  <li>从连接权限检查和限制中排除并行工作者。</li>
  <li>从 LWLock 等待事件名称中移除"Lock"后缀。</li>
  <li>修复窗口聚合中可能重用过时结果的问题。</li>
  <li>防止在关系截断过程中启动检查点。</li>
</ul>
<p>有关更多详细信息，请访问 <a href="https://www.postgresql.org/docs/release/17.3/" target="_blank">PostgreSQL 17.3 发布说明</a>。</p>

<h3 id="pg-17-4">PostgreSQL 17.4 增强功能</h3>
<ul>
  <li>改进 libpq 的引号处理函数行为。</li>
  <li>修复 pg_createsubscriber 中的小内存泄漏问题。</li>
  <li>修复 meson 构建系统以正确检测 bsd_auth.h 系统头文件的可用性。</li>
</ul>
<p>有关更多详细信息，请访问 <a href="https://www.postgresql.org/docs/release/17.4/" target="_blank">PostgreSQL 17.4 发布说明</a>。</p>

<h2 id="new-features">新功能</h2>

<h3 id="arm64">1. ARM64 架构全平台介质包</h3>
<p>提供适用于 ARM 架构的全平台介质包，支持国内外主流操作系统，包括 Red Hat、Debian、Kylin、UOS、NSAR OS 等。</p>

<h3 id="x86">2. X86 架构全平台介质包</h3>
<p>提供适用于 X86 架构的全平台介质包，支持国内外主流操作系统，包括 Red Hat、Debian、Kylin、UOS、NSAR OS 等。</p>

<h3 id="kernel-design">3. 新增内核架构设计专栏</h3>
<p>新增一系列内核架构设计文档，首个主题为 Oracle 兼容性，深入探讨每个模块的框架、设计和实现原理，旨在帮助用户深入理解 Oracle 兼容性框架。目前已经发布两个模块的架构设计文档：</p>
<ul>
  <li>Oracle 兼容性框架中的双 parser 架构原理分析</li>
  <li>Oracle 兼容性框架中的 initdb 架构原理分析</li>
</ul>

<h3 id="chatroom">4. IvorySQL 官方网站新增聊天室功能</h3>
<p>在官方网站上新增聊天室功能，支持与 IvorySQL 相关的智能互动和问答环节。</p>

<h2 id="resolved-issues">修复的问题</h2>
<ul>
  <li>使用不可见列和 pg_dump 时 SQL 不完整的问题</li>
  <li>EulerOS 的安装包问题</li>
</ul>
