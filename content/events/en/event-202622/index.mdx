**PGConf.Asia 2026 takes place on November 17–18 at InnoCentre in Hong Kong.** PostgreSQL users, engineers, developers, and contributors from across Asia and beyond will meet for two days of technical presentations and community exchange.

![PGConf.Asia 2026 official Hong Kong conference banner, November 17–18](/images/events/event-202622/banner.webp)

## A meeting point for Asia's PostgreSQL community

As PostgreSQL marks its thirtieth anniversary, the conference returns to Hong Kong to connect people working on the database and the applications built around it. PGConf.Asia has brought regional communities together since its first edition in Japan in 2016.

The program combines keynote presentations, parallel technical sessions, and opportunities to exchange experience with other practitioners. Its scope spans the database engine, production deployments, emerging workloads, and open-source collaboration.

## Program themes

- **Database engineering:** internals, extensions, performance, replication, and reliability.
- **Production operations:** availability, observability, backup, recovery, migrations, and deployment at scale.
- **Data platforms and AI:** cloud-native infrastructure, vector workloads, data pipelines, and applications.
- **Community collaboration:** user groups, upstream contributions, governance, and regional connections.

The published agenda includes Bruce Momjian on PostgreSQL's development and AI-generated SQL, Oleg Bartunov on the project's longer-term evolution, and sessions on Kubernetes, migrations, query performance, and security.

## IvorySQL session: Oracle compatibility through SQL parsing

**Building Oracle Compatibility in Databases from the Perspective of SQL Parser**

| Item | Details |
| --- | --- |
| Speakers | Shuntian Jiao and Zheng Tao |
| Time | November 18, 2026, 10:50–11:35 (Hong Kong time, UTC+8) |
| Room | Chamber 3 |
| Focus | Database internals, SQL parsing, and Oracle compatibility |

This session examines how differences between Oracle and PostgreSQL syntax affect database compatibility. It covers parser extensions, coexistence of multiple SQL dialects, and the implementation of compatibility features.

Using IvorySQL as its practical example, the presentation explores parser-level changes that support Oracle SQL while preserving maintainability and alignment with the PostgreSQL ecosystem.
