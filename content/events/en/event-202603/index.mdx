#
PostgreSQL & IvorySQL Tech Meetup・Zhengzhou — Successfully Held

📅 April 18, 2026 (Saturday) 13:30–18:00
📍 Zhengzhou East Railway Station Mixc World Joy City Hotel
🌍 Offline Event

On April 18, the PostgreSQL & IvorySQL Tech Meetup Zhengzhou was successfully held. As a warm-up event for HOW 2026, this small-scale offline gathering focused entirely on real-world database practices, hands-on experience, and technical discussions. Four speakers shared insights from their work, exchanging ideas with local developers, DBAs, and architects.

## Event Information

## Session Recap

01
Industry Customer Database Requirements & Implementation

- Addressing real-world challenges in database selection, migration, and operations

- Shared actionable implementation strategies based on project experience

Speaker: Ma Zhao

02
PG Users & Partners Practical Experience Sharing

- First-hand perspective on PostgreSQL deployment, daily tuning, and troubleshooting in production

- Shared practical methods and tips with high density of useful insights

Speaker: Fu Chao

03
PG Ecosystem Frontier Tech & Development Trends

- Senior PG ecosystem KOL shared cutting-edge insights on ecosystem dynamics, version features, and tech trends

- Helped developers stay ahead of the curve

04
IvorySQL Version Highlights & R&D Technical Insights

- Focused on IvorySQL kernel optimization, Oracle compatibility, and new version features

- Shared open-source R&D thinking and community co-building paths

Speaker: Tao Zheng

## Summary

This event marks an important milestone as IvorySQL Community's first independently organized small-scale offline tech meetup. The atmosphere was pure and interactions were deep — truly achieving the goal of "discussing PG ecosystem and exploring IvorySQL practices with like-minded tech professionals."

Thanks to all speakers, attendees, and our co-organizer, the PostgreSQL Branch of the Open Source Software Alliance. We will continue to visit more cities and build high-quality offline tech exchange communities.
