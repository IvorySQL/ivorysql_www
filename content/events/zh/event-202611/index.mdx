2026年7月25日（周六）下午，PostgreSQL & IvorySQL 技术交流 Meetup 南京站在南京市雨花台区网新数智中心南塔一楼紫金港厅成功举办。本次活动由 IvorySQL 社区、PG 分会、TechTalk 社区联合主办，南京橙时数据科技有限公司提供支持。来自南京及周边地区的 DBA、运维工程师、应用开发者、架构师、AI 工程师以及开源社区爱好者等近百位技术同仁齐聚一堂，围绕"深耕 PG 生态，聚焦内核与实践"的主题，展开了一场干货满满的技术交流。

## 活动信息

- **活动时间**：2026 年 7 月 25 日（周六）13:00–17:30
- **活动地点**：南京市雨花台区数字大道518号网新数智中心南塔一楼紫金港厅
- **主办单位**：IvorySQL 社区、PG 分会、TechTalk 社区

## 演讲回顾

1. **PostgreSQL 克隆，分支，与 PITR 黑魔法**（分享人：冯若航，Pigsty 作者、PG 扩展生态专家）
   介绍了如何利用 Pigsty / pig 命令行工具，对 PostgreSQL 进行数据库级、实例级、集群级的低成本快速克隆，以及时间点恢复（PITR）的实现方法，并通过文件系统挂载技术赋予工作区同样的"黑魔法"能力。

2. **PG 与 Agent 的双向奔赴**（分享人：白鳝，佰晟智算 CEO）
   深入探讨了 AI 时代下，以渐进式披露为核心的 AI Agent 如何为 PostgreSQL 的完全自主运维提供有力支撑，同时揭示了 PG 本身作为 AI Agent 开发热门平台的巨大潜力。

3. **以开源之力延展数据库边界：IvorySQL 的兼容与共建**（分享人：杨超超，IvorySQL 贡献者）
   围绕"兼容"与"共建"两条主线，详细介绍了 IvorySQL 在数据类型、语法、PL/SQL 等层面的 Oracle 兼容能力，并分享了如何借助开源社区的力量持续延展数据库的能力与价值边界。

4. **拒绝 AI 帮倒忙——数据库异常恢复 AI 最佳实践**（分享人：张晨，PostgreSQL ACE Partner、PDU 项目作者）
   结合真实案例，直面 AI 参与数据库异常恢复存在的真实风险，展示了如何在几小时内快速理解陌生运行环境、完成工具适配、定位异常根因并实现精准数据恢复的全过程。

5. **基于 repmgr 的 PostgreSQL 三节点高可用方案实战**（分享人：韩通，安徽云信达公司数智业务平台架构师）
   从环境准备、配置文件编写到自动故障转移验证，手把手带领大家完成了基于 repmgr 的 PostgreSQL 三节点高可用集群搭建的全流程实战演示。

6. **Workshop：Higobase + PGNexus 实战工作坊**（带领嘉宾：杨超超、尚雷）
   从工具安装到场景演练，快速上手了 Higobase 与 PGNexus 的联合实战，体验了企业级数据库运维与开发工具链的实际应用。Higobase：[higobase.highgo.com](https://higobase.highgo.com/) ｜ PGNexus：[pgnexus.ai](https://pgnexus.ai/home)

## 现场精彩

本次活动采用 50–100 人的精品规模，确保了每一位参会者都能与嘉宾进行充分互动。现场气氛热烈，每个议题结束后都引发了踊跃的提问与讨论。从 AI Agent 的准确度优化、AI 辅助异常恢复，到 PG 成为 AI Agent 开发热门平台的技术趋势，思想的碰撞贯穿全场。活动特别设置了提问有礼环节，到场参与者还有机会获得社区精心准备的周边礼品。更重要的是，本次活动为南京及周边地区的 PostgreSQL 与 IvorySQL 技术人搭建了一个面对面交流的平台，为建立南京 PG/IvorySQL 用户组迈出了坚实的一步。
