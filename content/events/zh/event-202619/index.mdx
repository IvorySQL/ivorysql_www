11 月 3 日，由数据库开源发展联盟（COSDA）与 IvorySQL 开源数据库社区联合主办的 IvorySQL 校园行·浙江大学宁波校区站在浙江大学软件学院顺利举办。

本次活动聚焦 PostgreSQL 技术生态、IvorySQL 的发展与创新、AI 与数据库融合等方向，通过三场主题演讲和一场动手实践 Workshop，为高校师生带来了从数据库内核原理、工程应用到实际操作的技术交流与学习体验。

![IvorySQL 校园行浙江大学宁波校区站活动开场](/images/events/event-202619/opening.webp)

## 开源技术走进校园，促进产学交流

作为数据库开源发展联盟（COSDA）“走进高校”系列活动的重要一站，本次浙江大学校园行延续了联盟推动开源数据库技术普及、促进产学交流的初衷。

IvorySQL 社区近年来持续开展高校技术交流活动，先后走进北京大学、山东大学等高校，通过技术分享与实践交流，帮助学生了解 PostgreSQL 技术生态、开源数据库的发展与实际应用。

此次活动进一步将数据库研发一线的技术经验带入校园，让高校学生有机会近距离接触开源数据库项目，了解相关技术的工程实践与发展方向。

## 三场技术分享，从数据库内核走向 AI 创新

### PostgreSQL 的可扩展性与“分支”生态

**分享嘉宾：德哥｜ PostgreSQL 中文社区发起人、COSDA 理事成员**

![德哥在浙江大学分享 PostgreSQL 的可扩展性与分支生态](/images/events/event-202619/digoal.webp)

PostgreSQL 以强大的可扩展性著称，但扩展机制能够解决哪些问题？什么时候又需要深入内核进行改造？

围绕这一问题，德哥从 PostgreSQL 的 SQL 与类型系统、Hook 机制、访问方法等方面，梳理了数据库扩展能力的不同层次及其技术边界。

分享以 IvorySQL 为案例，进一步探讨 PostgreSQL 扩展机制与内核分支之间的关系，以及 Oracle 兼容功能在实现过程中面临的技术选择。

从 `CREATE EXTENSION` 到内核修改，这一议题从架构设计与工程实践的角度，分析了 PostgreSQL 的可扩展能力，以及不同技术实现方式背后的取舍。

### 从兼容到智能：看 IvorySQL 的发展与创新

**分享嘉宾：梁翔宇｜ IvorySQL 核心贡献者、瀚高研发工程师**

![梁翔宇分享 IvorySQL 的发展与创新](/images/events/event-202619/liang-xiangyu.webp)

作为基于 PostgreSQL 构建的开源数据库项目，IvorySQL 在保持原生 PostgreSQL 兼容能力的基础上，持续探索 Oracle 兼容与数据库应用创新。

梁翔宇围绕 IvorySQL 的发展历程、开源初衷及技术演进展开分享，从 PostgreSQL 的可扩展架构切入，介绍了 IvorySQL 实现 Oracle 兼容的技术路径，以及相关能力在企业数据库迁移和应用开发中的价值。

随着 AI 技术与数据库的融合不断深入，数据库的应用场景也在持续拓展。结合 HighgoBase 智能数据基座及相关应用示例，分享进一步介绍了 AI 时代数据库技术在应用开发方面的新探索。

此外，梁翔宇还介绍了 IvorySQL 的容器化部署、云端体验与 PGNexus 等快速上手方式，以及开发者参与 IvorySQL 开源社区的相关路径。

### PostgreSQL × AI：从技术探索到 Sandbox 实验

**分享嘉宾：怀玉杰｜瀚高研发工程师**

![怀玉杰分享 PostgreSQL 与 AI 技术探索及 PGNexus Sandbox 实验](/images/events/event-202619/huai-yujie.webp)

对于 PostgreSQL 开发者而言，学习新版本特性、跟踪社区 Patch、理解技术讨论，以及搭建实验环境进行验证，都是日常技术探索的重要组成部分。

如何降低这些工作的操作成本，让技术学习与实验更加便捷？

怀玉杰围绕 PGNexus 平台展开介绍，分享了其在 PostgreSQL 技术信息获取、社区交流与实验验证方面的应用。

其中，PGNexus Sandbox 为开发者提供了便捷的数据库实验环境。通过浏览器即可创建不同版本的 PostgreSQL 及 IvorySQL 环境，并使用 psql 终端完成数据库操作。

围绕源码编译、Patch 验证、AI 对话和自动化测试等场景，分享展示了如何利用 Sandbox 将技术信息获取与实际实验相结合，帮助开发者从阅读、理解进一步走向动手验证。

[体验 PGNexus](https://pgnexus.ai)

## 从听到做：PGNexus Workshop 动手实践

除了主题演讲，本次活动还设置了 《PostgreSQL × AI 实战工作坊》，由怀玉杰、梁翔宇共同带领同学们开展数据库实践。

Workshop 以轻量化、易上手为原则，围绕 PGNexus Sandbox 展开。同学们通过平台注册和在线实验环境，体验 PostgreSQL 与 IvorySQL 数据库的快速部署，并使用 psql 终端进行基础 SQL 操作与功能验证。

与传统的本地数据库环境搭建相比，PGNexus Sandbox 简化了实验环境的准备过程，使参与者能够将更多精力投入到数据库技术的学习与实际操作中。

通过主题演讲与 Workshop 的结合，本次活动将 PostgreSQL、IvorySQL 的技术知识与实际操作相衔接，让同学们在了解技术原理的同时，也能够亲自体验开源数据库的使用与实践。

## 连接高校与开源社区，让技术交流持续延伸

开源数据库的发展不仅依赖技术创新，也离不开开发者社区与高校人才的持续参与。

对于高校学生而言，参与开源项目既是学习技术的一种方式，也是了解软件工程实践、积累项目经验的重要途径。从使用开源软件，到阅读文档、提出 Issue、参与技术讨论，再到尝试提交代码贡献，开源社区为不同技术基础的开发者提供了多样化的参与方式。

IvorySQL 社区持续通过技术分享、校园行、开源贡献活动等形式，为高校师生搭建与开源项目、研发工程师交流的平台，鼓励更多学生从开源技术的学习者逐步成长为社区参与者和贡献者。

此次浙江大学校园行也为高校师生进一步了解 PostgreSQL、IvorySQL 及相关开源项目提供了交流机会。

![IvorySQL 校园行浙江大学宁波校区站师生现场合影](/images/events/event-202619/group-photo.webp)

## 持续走进高校，共建开源数据库生态

从 PostgreSQL 的内核与扩展机制，到 IvorySQL 的兼容能力和技术创新，再到 PGNexus 带来的在线实验体验，本次校园行通过技术分享与动手实践相结合的形式，为高校学生提供了了解开源数据库技术与产业实践的机会。

未来，IvorySQL 社区将继续联合 COSDA 等生态伙伴，推动开源数据库技术走进更多高校，围绕技术交流、实践教学与社区贡献开展合作，为青年开发者提供更多学习、交流和参与开源的机会。

让开源技术走进校园，让更多青年开发者在实践中探索数据库技术的更多可能。
