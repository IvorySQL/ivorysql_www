**PGConf.Asia 2026 将于 11 月 17—18 日在中国香港 InnoCentre 创新中心举办。** 来自亚洲及全球的 PostgreSQL 用户、数据库工程师、开发者和开源贡献者将齐聚香港，围绕技术演进、生产实践与社区协作展开为期两天的交流。

![PGConf.Asia 2026 香港大会官方宣传图：11 月 17—18 日](/images/events/event-202622/banner.webp)

## 连接亚洲社区，交流 PostgreSQL 实践

2026 年，PostgreSQL 迎来 30 周年。自 2016 年首届大会在日本举办以来，PGConf.Asia 持续连接亚洲各地的用户、开发者与社区。今年大会重返香港，通过主题演讲、并行技术分享及社区交流，为不同技术背景的参与者搭建面对面交流的平台。

本届大会的内容涵盖数据库底层机制与实际应用，也关注开源基础设施在云原生、数据分析和 AI 场景中的发展。无论是维护生产系统、研究数据库内核，还是探索新的应用架构，都能从大会中找到值得讨论的技术问题。

## 大会议程关注什么

- **数据库工程：** 内核机制、扩展开发、性能优化、复制与逻辑解码，以及数据库可靠性。
- **运维与生产实践：** 高可用、监控与可观测性、备份恢复、数据库迁移，以及规模化部署经验。
- **数据平台与 AI：** 云原生部署、向量检索、AI 数据管道，以及基于 PostgreSQL 构建的应用。
- **社区与开源协作：** 区域用户组、上游贡献、项目治理与跨社区交流。

官方议程包含 Bruce Momjian 对 PostgreSQL 发展方向及 AI 与 SQL 的讨论、Oleg Bartunov 对 PostgreSQL 长期演进的分享，以及 Kubernetes 部署、Oracle 迁移、查询性能、数据库安全等主题。参会者可以按照自己的技术方向选择并行会场。

[查看大会完整议程](https://pgconf.asia/EN/2026/schedule/)

## IvorySQL 议题：从 SQL Parser 视角构建 Oracle 兼容能力

**Building Oracle Compatibility in Databases from the Perspective of SQL Parser**

| 项目 | 信息 |
| --- | --- |
| 分享嘉宾 | 矫顺田（Shuntian Jiao）、陶郑（Zheng Tao） |
| 演讲时间 | 2026 年 11 月 18 日 10:50—11:35（香港时间，UTC+8） |
| 会场 | Chamber 3 |
| 技术方向 | 数据库内核开发、SQL 解析与 Oracle 兼容 |

SQL Parser 是数据库实现多语法兼容的重要入口。本场分享将围绕 Oracle 与 PostgreSQL 的语法差异、解析器扩展、多语法共存以及兼容特性的实现展开讨论。

议题以 IvorySQL 的开发实践为例，介绍如何通过解析层增强 Oracle SQL 兼容能力，并兼顾代码的可维护性与 PostgreSQL 生态的一致性，为数据库兼容开发和迁移实践提供技术参考。
