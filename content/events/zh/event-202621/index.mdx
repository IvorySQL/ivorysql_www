上一届乌镇开源竞技挑战赛结束后，新一轮 **开放原子大赛开源贡献赛事** 接力开启。IvorySQL 社区邀请开发者继续参与真实开源项目，在社区协作中积累工程经验，并通过有效贡献评价争取现金奖励。

[查看 IvorySQL 赛题并报名参赛](https://www.taiyi.top/competition-details?id=0599fdec-bc9a-11f1-8bb8-02420a000047)

![开放原子大赛开源贡献赛道官方页面宣传图](/images/events/event-202621/banner.webp)

## 赛事信息

- **赛事：** 第四届开放原子大赛开源贡献赛道（滚动赛制，2026 年第 4 季度）
- **IvorySQL 赛题周期：** 2026 年 10 月 25 日 00:00 至 12 月 31 日 23:59（北京时间，UTC+8）
- **参与方式：** 在太乙平台报名，参与 IvorySQL 项目开发，通过 GitHub 提交贡献
- **面向人群：** 开发者、在校学生及开源爱好者，欢迎首次参与开源项目的朋友

赛事的有效贡献认定、奖金分配与赛程安排，以 [太乙平台 IvorySQL 赛题页面](https://www.taiyi.top/competition-details?id=0599fdec-bc9a-11f1-8bb8-02420a000047) 公布的规则为准。

## 让真实贡献获得认可

赛事关注开发者为项目带来的真实价值。高质量的功能开发、缺陷修复和代码改进，都有机会成为获得奖励的有效贡献。

贡献评价关注质量、难度以及对项目产生的实际作用。参赛者在真实项目中解决问题、积累工程实践经验，也能通过社区协作留下可追溯的开源贡献记录。

![开源贡献赛道关于贡献质量、社区协作和自动评价的介绍](/images/events/event-202621/overview.webp)

## 在 IvorySQL 找到适合自己的方向

IvorySQL 基于 PostgreSQL 开发，在保持原生 PostgreSQL 兼容能力的基础上，持续增强 Oracle 兼容能力，为企业数据库迁移与应用开发提供更多选择。

- 熟悉 PostgreSQL 或 C 语言的开发者，可以深入数据库内核，参与功能开发、缺陷修复和性能优化。
- 对数据库技术感兴趣的开发者，可以从兼容性测试、工具改进、自动化测试等方向寻找贡献机会。
- 初次参与者可以通过 `good first issue` 标签，寻找适合入门的任务，从问题分析、代码修改到提交 Pull Request，逐步熟悉社区协作流程。

[查找 IvorySQL Good First Issue 任务](https://github.com/IvorySQL/IvorySQL/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22)

![IvorySQL 仓库中的 Good First Issue 任务示例](/images/events/event-202621/good-first-issues.webp)

## 如何参加

### 第一步：了解规则并报名

进入 [太乙平台 IvorySQL 赛题页面](https://www.taiyi.top/competition-details?id=0599fdec-bc9a-11f1-8bb8-02420a000047)，了解参赛条件、赛程安排、奖金规则与贡献认定要求，并根据平台提示完成报名。

### 第二步：选择任务

浏览 [IvorySQL 内核仓库](https://github.com/IvorySQL/IvorySQL) 中的 Issue、文档与贡献指南，也可以从 [IvorySQL 项目仓库群](https://github.com/IvorySQL/) 寻找适合自己的参与方向。

### 第三步：开发、测试并提交 Pull Request

按照项目贡献规范开展开发与测试，通过 GitHub 提交 Pull Request，与社区维护者协作完善代码。

### 第四步：关联有效贡献，参与赛事评价

根据太乙平台要求完成贡献关联、申报或其他必要操作。**贡献被合并的时间需在比赛周期内。**符合赛事规则的有效贡献，将按官方评价与奖金分配机制参与奖励核算。
